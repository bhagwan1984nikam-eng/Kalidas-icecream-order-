Kalidas Ice Cream Order App — Route-wise version

1. GitHub Repository उघडा.
2. जुन्या index.html ऐवजी या ZIP मधील index.html अपलोड करा.
3. Commit changes करा.
4. ॲपमध्ये दुकाने विभागात प्रत्येक दुकानासाठी रूटचे नाव भरा (उदा. कुडाळ रूट, बांदा रूट, एकरूळ रूट).
5. ऑर्डर विभागात रूट निवडल्यावर त्या रूटची दुकानेच दिसतील. सर्व रूट निवडल्यास सर्व दुकाने दिसतील.
6. CSV Import मध्ये Route/रूट नावाचा कॉलम असल्यास दुकान योग्य रूटमध्ये येईल. जुनी CSV असल्यास रूट कॉलम नसल्यामुळे दुकाने 'रूट नाही' म्हणून येतील; त्यांना ॲपमध्ये पुन्हा योग्य रूट द्या.
7. आधीचा डेटा जतन करण्यासाठी बदल करण्याआधी पूर्ण बॅकअप डाउनलोड करा.
